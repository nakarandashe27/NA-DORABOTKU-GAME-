# Idea — «НА ДОРАБОТКУ»

Тёмно-абсурдный симулятор рутины стажёра-«батракана» в архбюро: проверка чертежей как в Papers, Please, голоса-навыки как в Disco Elysium, ИИ-стажёр-антагонист, живой ASCII-визуал и процедурный звук. Браузер + Telegram, русский язык. Цель — сначала пет-проект/портфолио, при успехе — вирусность и коммерция.
