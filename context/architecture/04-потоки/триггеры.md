# Триггеры

> Этап «4 слоя памяти» пропущен: в игре нет AI/LLM во время работы. ИИ-стажёр — заскриптованный персонаж, его «ошибки» — авторский контент. Qwen3-TTS (шаг 2) — офлайн-генерация аудиофайлов при сборке, не рантайм.

Всё на шагах 0–1 работает **в клиенте** (< 16 мс на кадр, отклик на тап < 100 мс); сейв асинхронный, но не блокирует игру. Фона и расписания нет — нет сервера. Время игры — только накопленный `dt` с ограничением 100 мс за кадр; пауза — событие платформы, не часы. Пересмотрено после [премортема архитектуры](../07-нефункциональные/риски-архитектуры.md) (риски 5, 6, 8).

| Триггер | Тип | Что делает | Лимит времени | Защита от дублей | При сбое |
|---|---|---|---|---|---|
| Запуск: 1) платформа | действие юзера | `platform.start()`: определить канал, в Telegram дождаться готовности SDK, получить `startParam` | ≤ 500 мс; дольше → считать «браузер» | — | SDK не загрузился → режим браузера |
| Запуск: 2) сейв | внутреннее | `saveStore.load()` из всех доступных копий → миграция → слияние | ≤ 300 мс | — | копия битая → бэкап в `save.backup.*`, слияние без неё; все битые → новый сейв |
| Запуск: 3) контент | внутреннее | загрузить контент, применить `renames.json` к сейву | общая загрузка < 2 с ([метрики](../../idea/04-mvp/success-metrics.md)) | — | контент битый (не должен — валидатор в CI) → экран ошибки с версией сборки |
| Запуск: 4) сцена | внутреннее | `boot` → `office` или лист из `startParam` (если такой есть в контенте) | — | — | неизвестный `startParam` → игнор |
| Старые файлы сборки не найдены (404 после деплоя) | внешнее | один раз перезагрузить страницу с новой версией ([деплой](../07-нефункциональные/деплой.md)) | — | флаг «уже перезагружались» в sessionStorage | второй 404 → экран «обнови игру» |
| Первый жест (`click`/`pointerup`) | действие юзера | `audio.unlock()`: создать/возобновить AudioContext; автомат `locked → running` | синхронно в обработчике | повторный unlock безопасен | не стартовал → состояние `locked`, игра без звука, индикатор «звук выкл» |
| Звук прерван (звонок, сворачивание на iOS) | внешнее | автомат → `interrupted`/`suspended` | — | — | возобновление по следующему жесту игрока |
| Тап по области листа | действие юзера | проверить попадание в ошибку → засчитать / штраф | < 100 мс | ошибку можно засчитать один раз | — |
| «Послушать голос» | действие юзера | показать подсказку голоса, −1 из лимита | синхронно | кнопка неактивна при лимите 0 | — |
| Штамп (СОГЛАСОВАНО / НА ДОРАБОТКУ) | действие юзера | закрыть лист, посчитать итог, реплика ГАПа, обновить навык/репутацию | синхронно | лист закрывается один раз (идемпотентно по id листа) | — |
| Время листа истекло | внутреннее | автоштамп «НА ДОРАБОТКУ», итог | по таймеру игры | одно срабатывание на лист | — |
| Лист закрыт | внутреннее | `rev + 1`, сохранить сейв через `SaveStore` (local и CloudStorage, асинхронно, не блокирует игру) | — | копии **сливаются** по правилам из [сущностей](../03-данные/сущности.md), время устройства не арбитр | CloudStorage упал → только local, повтор при следующем сохранении |
| Условие события выполнено (напр. глава 1 пройдена) | внутреннее | запустить событие (приход ИИ-стажёра) | — | флаг события в сейве | — |
| Приложение свёрнуто / вкладка скрыта (`visibilitychange` в браузере; события `deactivated` Telegram — через `Platform.lifecycle`) | внешнее (платформа) | пауза таймера листа, сохранить сейв, приостановить звук | синхронно | — | — |
| Приложение развёрнуто (`activated` / `visibilitychange`) | внешнее (платформа) | снять паузу; накопленное время **не** засчитывается (`dt` ≤ 100 мс за кадр) | синхронно | — | звук не возобновился → ждём жест |
| Потеря WebGL-контекста (`webglcontextlost`) | внешнее | остановить отрисовку, не терять состояние игры | — | — | ждать `restored` |
| Восстановление контекста (`webglcontextrestored`) | внешнее | пересоздать атлас, буферы, шейдеры; перерисовать из буфера ячеек | ≤ 1 с | — | не восстановился за 3 с → переключиться на Canvas2D |
| Кадр дольше бюджета (16 мс на 360×640) N кадров подряд | внутреннее | понизить качество: меньше анимаций травы/воды, реже обновление фона | — | гистерезис, чтобы не мигать | на Canvas2D — минимальный режим |
| Изменение viewport / поворот | внешнее (платформа) | пересчитать сетку глифов | ≤ 1 кадр | debounce | — |
| Экспорт / импорт «кода сейва» | действие юзера | экспорт строки; импорт → проверка контрольной суммы → слияние | синхронно | слияние идемпотентно | неверный код → сообщение, сейв не трогаем |
| «Поделиться моментом» | действие юзера | Telegram: `shareMessage`/ссылка с `startapp`; браузер: Web Share API или копирование ссылки | синхронно | — | шаринг недоступен → скопировать ссылку |

## Шаг 2 💡
| Триггер | Тип | Что делает | Режим |
|---|---|---|---|
| Сейв изменился | внутреннее | отправка на сервер | асинхронно, повтор с backoff |
| Вход через Telegram / запасной вход | действие юзера | сервер проверяет `initData` (HMAC) → сессия | синхронно |
| Напоминание от бота | по расписанию | отложено — см. [proactive](../../idea/06-principles/proactive.md) | — |
