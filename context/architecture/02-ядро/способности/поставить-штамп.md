# способность: поставить-штамп

## Когда применять
Игрок закончил проверку и выбирает СОГЛАСОВАНО или НА ДОРАБОТКУ. Также автоштамп НА ДОРАБОТКУ по истечении времени.

## Когда НЕ применять
Лист уже закрыт — повторный штамп игнорируется (идемпотентно по id листа, см. [триггеры](../../04-потоки/триггеры.md)).

## Примеры
- Good: СОГЛАСОВАНО при найденных всех ошибках → реплика ГАПа, +навык, +репутация, сейв.
- Good: СОГЛАСОВАНО «как есть» с пропущенными ошибками → это выбор «сделать плохо» ([action-oriented](../../../idea/06-principles/action-oriented.md)): быстрее, но последствия.
- Bad: окно «Вы уверены?» перед штампом — противоречит action-oriented.

## Что может пойти не так
Сейв не записался → итог листа всё равно показан, сохранение повторяется при следующем триггере.
