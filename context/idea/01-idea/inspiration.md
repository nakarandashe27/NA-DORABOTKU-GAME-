# Вдохновение и референсы

## Визуальный референс — `IMG_0054.MP4`

Подпись в ролике: «Making the ASCII MMORPG of my dreams — Water reflection test». 720×1280, 30 fps, 30 с.

**Что на самом деле видно:** это не пиксель-арт, а **ASCII-рендер**. Сцена (трава, вода, замок, деревья, персонаж) рисуется моноширинными символами на тёмном фоне:
- Трава — сотни зелёных штрихов `/ | \` разных оттенков, колышутся; поверх мерцают «светлячки» `o * .`.
- Вода — тёмная зона, рябь из `~ ( ) / \ =`, концентрические кольца вокруг персонажа; отражение персонажа и луны снизу, с искажением.
- Камень/стены/кусты — плотные символы `@ # $ 8 Q W M` (яркость → плотность глифа).
- Персонаж — тоже из символов, но плотнее и с цветом; над ним никнейм.
- Есть глубина: дальние объекты тусклее, ближние — контрастнее; цветовые пятна (оранжевые фонари).

**Как это вероятно сделано:** сцена рендерится в низкое разрешение (буфер яркость+цвет+нормаль), затем каждая ячейка сетки ~6×10 px заменяется символом, выбранным по яркости (density ramp) и/или по направлению края (`/ \ | -` для контуров). Анимация — шум/синусы по времени. Вода — отражённый буфер + смещение по синусу.

## Скилл procedural-film
Источник: https://github.com/kuhnhomeuk-cell/procedural-film (проверено 2026-10-13).
Всё рисуется в canvas на vanilla JS, звук — Web Audio, без ассетов. Есть retro-режим 320×180 / 60 fps с эмуляцией NES-звука и стартовый платформер. Полезно как: (а) подход «всё кодом», (б) шаблоны планирования шотов/сцен для катсцен, (в) синтез 8-бит звука. Нарративной методологии как таковой в описании нет.

## Игровые референсы (выбор 2026-10-13)

### Papers, Please — что берём
- Рутинная бюрократическая работа как сам геймплей: проверка документов ↔ проверка чертежей/штампов/спецификаций.
- Нарастающая сложность правил: каждый «день/уровень» добавляет новое правило (нормы, ГОСТы, хотелки заказчика).
- Моральные микровыборы под давлением времени (подписать с ошибкой, чтобы успеть, или задержать сдачу).
- Мрачный минималистичный тон.

### Disco Elysium — что берём
- Навыки как «голоса в голове»: «Черчение», «BIM», «Умение казаться занятым» комментируют ситуации и подсказывают варианты в диалогах.
- Абсурдные, хорошо написанные диалоги как основной носитель юмора.
- Провал — тоже контент: неудачные исходы интересны, а не просто «Game Over».

### Отклонено
- Stardew/Animal Crossing (уютный ритм) — не наш тон, хотя хаб с NPC структурно похож.
- WarioWare (микро-игры по 5 с) — слишком хаотично; задачи длиннее и «бумажнее».

## Мем-референс
Вероятно — **«Конторка» / «батраканы»**: нейросетевой мини-сериал Instagram-аккаунта @ooo_slop (с середины августа 2026). Сотрудники — «батраканы» (от «батрак»), зарплата — «кукиши», над всеми невидимый «Хозяин»; тренд-аудио «Наш батракан колупает циферки в конторке». Один ролик ~600K просмотров [источник — в ресёрче, см. 05-research]. Есть iOS-фан-игра «Конторка: батракан в офисе» — ближайший структурный аналог.
Подтверждено пользователем 2026-10-13: это тот самый мем («батракан»).

**Что берём:** приём «выдуманный корпоративный жаргон» — у нашего бюро будет свой жаргон, но **не копируем лор @ooo_slop** (батраканы/кукиши/Хозяин — чужая IP). Отличие: профессиональный архитектурный контекст + ИИ-антагонист.
