# НА ДОРАБОТКУ — контекст проекта

Тёмно-абсурдная игра про стажёра архбюро: проверка чертежей в духе Papers, Please, ИИ-стажёр-антагонист, живой ASCII-визуал; браузер + Telegram, русский язык.

**Правило:** при работе читай только нужный файл, не загружай всё сразу.

| [idea/](idea/README.md) | замысел: зачем, для кого, MVP, ресёрч, принципы, риски идеи | [README](idea/README.md) |
| [architecture/](architecture/README.md) | чертёж: система, данные, потоки, стек, тесты, деплой, **roadmap** | [roadmap](architecture/08-дорожная-карта/roadmap.md) |
