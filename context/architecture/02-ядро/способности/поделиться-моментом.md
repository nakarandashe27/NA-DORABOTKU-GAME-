# способность: поделиться-моментом

## Когда применять
После штампа с репликой ГАПа или после сцены с ИИ-стажёром — игрок хочет скинуть момент в чат (JTBD №2).

## Когда НЕ применять
Не навязывать: никаких принудительных шарингов за награду.

## Примеры
- Good (Telegram, шаги 0–1): `openTelegramLink('https://t.me/share/url?url=<бот>?startapp=<sheetId>&text=…')` — друг открывает тот же лист. `shareMessage` (Bot API 8.0) требует сообщение, подготовленное **сервером** бота (`savePreparedInlineMessage`), — доступен только с шага 2 (сверено с core.telegram.org/bots/webapps, 2026-10-13).
- Good (браузер): Web Share API или «ссылка скопирована» + картинка-скрин ASCII-кадра.
- Bad: шаринг ради бонусов — паттерн tap-to-earn ([what-to-avoid §4](../../../idea/05-research/what-to-avoid.md)).

## Что может пойти не так
API недоступно (Telegram заблокирован/старый клиент) → копирование ссылки.
