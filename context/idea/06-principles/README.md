# 06 · Принципы

Правила, которые влияют на архитектуру и дизайн. Каждый выведен из [ресёрча](../05-research/README.md) или болей [аудитории](../03-audience/jobs-to-be-done.md). Приняты пользователем 2026-10-13 (вкл. голоса-навыки как ограниченный ресурс и дублирование сейва в CloudStorage).

1. **Сатира через механику, не через текст.** Юмор — в штампе, ошибке ИИ, комментарии ГАПа; никаких лекций. ← [what-to-steal #18](../05-research/what-to-steal.md), [what-to-avoid §3](../05-research/what-to-avoid.md)
2. **Никакой угадайки.** Каждая ошибка на чертеже выводима из правил и инструментов проверки. ← главная претензия к Papers-клонам ([what-to-avoid §1](../05-research/what-to-avoid.md))
3. **Сюжет живёт внутри работы.** Голоса, реплики и выборы возникают во время проверки листа, не в паузах. ← [what-to-steal #4](../05-research/what-to-steal.md)
4. **Рутина хороша без сюжета.** Мини-игра должна залипать сама по себе. ← критерий «Залипательно» ([success-criteria](../02-vision/success-criteria.md))
5. **Всё кодом.** ASCII-графика и звук процедурные, без картинок и аудиофайлов → маленький билд, загрузка < 2 с. ← [inspiration](../01-idea/inspiration.md), [метрики](../04-mvp/success-metrics.md)
6. **Один код — два равных канала.** Браузер и Telegram — одна сборка; фичи Telegram — опциональный слой, игра работает без него. ← решение по каналам, риск РФ ([ресёрч](../05-research/README.md))
7. **Свой жаргон, чужой лор не трогаем.** ← [what-to-avoid §2](../05-research/what-to-avoid.md)
8. **Соло-скоуп.** Фича, не нужная для текущего шага (демо → срез → глава), не делается. ← [one-person-company](one-person-company.md)

Подробно: [local-first](local-first.md) · [proactive](proactive.md) · [action-oriented](action-oriented.md) · [one-person-company](one-person-company.md)

## Решение: озвучка (2026-10-13)
- **Демо и MVP:** без голоса — персонажи «бормочут» процедурным 8-бит звуком (как Animal Crossing). Принцип 5 соблюдён полностью.
- **Шаг 2:** свой голос (автор или друг с согласием), клонированный через Qwen3-TTS, канцелярская монотонная подача «в духе Конторки». Голос «Конторки» **не клонируем** (принцип 7).
- Уточнение принципа 5 со шага 2: графика и SFX — код, голос — небольшой набор коротких аудиофайлов.
