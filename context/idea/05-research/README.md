# 05 · Ресёрч: что уже есть и чем мы отличаемся

Дата проверки всех источников: 2026-10-13. Пометки: `[непроверено]` — нет подтверждения прочтением первоисточника; `[вывод]` — наша интерпретация, не факт из источника.

## TL;DR по пяти углам

1. **Офисная рутина как геймплей.** Жанр Papers, Please живой и плотный: 11 найденных аналогов, у лидеров Steam «Very/Overwhelmingly Positive». Закономерность: правила копятся, поверх сверки есть «вторая игра» (деньги, рейтинг, босс), жанр иногда эскалирует в странное. Типичные провалы клонов: исход как угадайка, повторяемость, слабая сюжетная часть, ярлык «клон Papers, Please». Подробно: [аналоги](analogs.md), [методики](methodologies.md).
2. **Архитекторы и «Конторка».** Прямых аналогов «стажёр-архитектор + проверка чертежей» **не найдено**, но поиск был неглубоким. Зато найден самый близкий по структуре конкурент: iOS-игра «Конторка: батракан в офисе» (фан-игра по мему @ooo_slop: рабочий стол и мини-игры в окнах). Проверенные боли профессии для контента: правки заказчика, недосып и сверхурочные, спор Archicad/Revit, экспертиза. Буквальный мем «таракан в офисе» **не подтверждён**, найден «Конторка/батраканы».
3. **ASCII-рендер.** Задача реалистична (Asciicker уже делает цветные глифы с отражением воды в браузере). Рекомендация исследования: своя тонкая сетка глифов на WebGL2 (instanced quads + атлас), fallback на Canvas2D; игра пишет прямо в сетку ячеек без промежуточной картинки. FPS на целевом Android в Telegram WebView — **не измерен**.
4. **Telegram Mini Apps.** Для нарративного юмора рынок не валидирован (нон-крипто нарративных примеров с метриками не найдено); tap-to-earn обвалился из-за «пустоты». Платформа даёт полезные для нас вещи: `shareMessage`, deep link `?startapp=`, CloudStorage, `addToHomeScreen`, класс производительности в User-Agent.
5. **Сатира про ИИ.** Ракурс «человек-джун, которого вытесняют» по найденному свободен (большинство игр смотрят глазами ИИ или корпорации). Реальный фон есть: RIBA 2026, METR, Klarna. Главная граница — не морализировать (Cat Secretary уже ловит упрёк «в лоб»).

## Главная дельта нашей идеи

Профессиональный контекст архбюро (чертежи, ГАП, правки, экспертиза) + проверка чертежа в духе Papers, Please + «голоса-навыки» + человек-джун против ИИ-стажёра + живой ASCII, на русском, в браузере и Telegram. Каждый элемент по отдельности встречается; уникальна **связка**, и это пока [вывод]. Подробно и с оговорками: [дельта](delta.md).

## Топ-3 риска, всплывших в ресёрче

1. **Telegram в РФ: замедление и блокировки 2026.** 10.02.2026 Роскомнадзор подтвердил замедление по стране; по данным OONI на 10.04.2026 доля аномалий блокировки 95%; Дуров: ~65 млн россиян ходят через VPN. Состояние именно на октябрь 2026 — [непроверено]. **Следствие: браузерная версия обязательна, Telegram — дополнительный канал, а не единственный.** источник: https://meduza.io/en/news/2026/02/10/russia-s-federal-censorship-agency-reportedly-begins-slowing-telegram-nationwide (проверено 2026-10-13); источник: https://ru.wikipedia.org/wiki/Блокировка_Telegram_в_России_(2026) (проверено 2026-10-13). **Решение (2026-10-13):** оба канала равноправны с первого дня, риск принят — см. [идея](../01-idea/README.md).
2. **Игра как «угадайка» или «клон Papers, Please».** Две типичные претензии к последователям жанра (Lil' Guardsman, Not Tonight). Лечится выводимостью ответа (правила и ограниченные инструменты проверки) и тем, что сюжет живёт внутри проверки, а не между задачами. Подробно: [что избегать](what-to-avoid.md).
3. **Производительность и звук на мобильных WebView.** Целевые метрики демо (≥ 50 fps, загрузка < 2 с, см. [метрики](../04-mvp/success-metrics.md)) не подтверждены замером; Web Audio на iOS требует жеста `click`, `touchstart` в отчётах WebKit не засчитывается. Первый шаг — однодневный замер прототипа на реальном Android в Telegram. Подробно: [что избегать](what-to-avoid.md).

Ещё два риска меньшего веса: ложное «мы первые» (поиск по Steam/itch.io поверхностный) и зависимость от закрытых исходников textmode.js, если брать его как быстрый старт.
