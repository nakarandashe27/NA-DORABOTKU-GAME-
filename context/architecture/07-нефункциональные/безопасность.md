# Безопасность

Масштаб угроз маленький: одиночная игра без аккаунтов, без денег и без сервера на шагах 0–1. Связано: [права доступа](../02-ядро/права-доступа.md), [границы](../01-обзор/границы.md).

## Шаги 0–1
- **Секреты:** их нет. В клиенте не должно быть ни токена бота, ни ключей — всё, что в сборке, публично. Токен бота (если понадобится для настройки) — только в GitHub Secrets / у автора, никогда в репозитории.
- **Журнал действий:** не нужен; в dev — лог неизвестных id сейва и ошибок миграции.
- **Личные данные:** не собираются. Сейв содержит анонимный `playerId` и прогресс; Telegram-данные пользователя (имя, id) в сейв **не пишутся** ([отказы](../02-ядро/характер.md)). Аналитика — без персональных данных.
- **Вход:** нет.
- **Проверка прав:** нечего проверять — все действия локальны; подделка сейва игроком ни на что не влияет (рейтингов нет).
- **Недоверенный ввод:** `startParam` из ссылки — только id из контента, иначе игнор; «код сейва» — проверка контрольной суммы и схемы, затем слияние; ни то, ни другое не исполняется как код и не вставляется в DOM как HTML.
- **Сторонние скрипты:** только `telegram-web-app.js` с telegram.org и только внутри Telegram; никаких рекламных/трекинговых SDK.
- **Лимиты на запросы:** запросов нет.

## Шаг 2 💡 (до начала шага — обязательно)
- **Вход:** Telegram — проверка `initData` на сервере (HMAC токеном бота) + срок жизни по `auth_date` (порог — [заполнить], напр. 24 ч). **Запасной вход** (если Telegram недоступен в РФ) — решить до шага 2: «код сейва» как ручной перенос / magic-link на email / без запасного входа. Пароли — не используем.
- **152-ФЗ:** сервер и БД в РФ; Telegram ID считаем персональными данными; согласие и политика конфиденциальности [проверить с юристом] ([технологии](../05-стек/технологии.md)).
- **Валидация прогресса:** сервер прогоняет присланный сейв через тот же `content-schema` (схема, ссылки, монотонность), а не доверяет ему.
- **Лимиты:** на сохранение — не чаще 1 раза в 5 с на игрока; размер тела ≤ 8 КБ.
- **CORS:** только свой домен игры.
- **Секреты сервера:** токен бота и строка БД — только в переменных окружения.

## Проверка «опасной тройки»
Не применяется: в игре нет AI-агента, который читает ненадёжное содержимое и отправляет наружу.
