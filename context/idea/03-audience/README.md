# 03 · Аудитория

Ядро — **действующие архитекторы и проектировщики** (джуны, ГИП/ГАП, BIM-специалисты): понимают каждую шутку, узнают себя, разносят по рабочим чатам. Рядом — **студенты-архитекторы**, для которых игра — ироничный «трейлер» будущей работы, и **любители инди/ASCII-эстетики**, которые приходят ради визуала. Офисные работники вообще — не цель (выбор 2026-10-13): юмор не размываем ради широты.
