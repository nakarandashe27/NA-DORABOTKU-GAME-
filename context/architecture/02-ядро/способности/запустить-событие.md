# способность: запустить-событие

## Когда применять
Выполнено условие `condition` из записи `event` (например, глава пройдена → приходит ИИ-стажёр; рутина «ломается» перед ним).

## Когда НЕ применять
Событие уже было (флаг в сейве) — не повторять.

## Примеры
- Good: после 5-го листа — сцена дуэли с ИИ-стажёром ([золотая сцена](../../../idea/04-mvp/one-killer-feature.md)).
- Bad: событие прерывает проверку листа в середине. Событие ставится в очередь и стартует после штампа; сцена `cutscene` кладётся поверх стека сцен ([карта системы](../../01-обзор/карта-системы.md#сцены)).

## Что может пойти не так
Условие ссылается на несуществующий id → ловит валидатор контента при сборке ([главный кирпич](../../03-данные/главный-кирпич.md)).
