# Action-oriented: действие важнее текста

(Шаблон скилла — «что агент делает без подтверждения»; для игры переложено как «что игрок делает без лишних шагов».)

- **Каждое взаимодействие — тап/клик, без диалогов-подтверждений.** Нашёл ошибку — тапнул; поставил штамп — готово.
- **Штамп необратим в пределах листа, но рестарт дешёвый.** Лист 2–5 мин, штрафы честные и обнуляемые, без «залипающих» последствий. ← [what-to-steal #20](../05-research/what-to-steal.md)
- **Опция «сделать плохо»** — подписать как есть ради скорости; это выбор, а не ошибка интерфейса. ← [what-to-steal #6](../05-research/what-to-steal.md)
- **Новое правило подаётся «в лицо»** — рядом с чертежом/в момент ошибки, не текстом перед сменой. ← [what-to-steal #1](../05-research/what-to-steal.md)
- **Звук включается первым кликом** (iOS требует `click`). ← [what-to-steal #17](../05-research/what-to-steal.md)
