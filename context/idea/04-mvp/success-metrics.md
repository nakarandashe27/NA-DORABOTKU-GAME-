# Метрики MVP

Выбор 2026-10-13: качественный + технический сигнал для демо, количественный — для MVP.

## Демо (шаг 0) — критерии перехода к MVP
**Качественный (плейтест):** 10 знакомых архитекторов.
- ≥ 5 из 10 сами прошли все листы без уговоров.
- ≥ 3 из 10 переслали скрин/ссылку кому-то ещё (проверка JTBD №2).

**Технический:**
- ASCII-сцена ≥ 50 fps на среднем Android (≈ 15 тыс. ₽).
- Загрузка в Telegram Web App < 2 с.
