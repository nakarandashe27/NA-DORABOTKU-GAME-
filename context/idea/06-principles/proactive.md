# Proactive: где игра действует сама

Игра не ждёт игрока — офис живёт (тон Кафки, «таракан в бесконечной рутине»):
- **ГАП приходит сам** — кидает лист на стол, вмешивается в проверку.
- **Голоса-навыки комментируют без запроса** в моменты ошибок/подозрений (Disco Elysium), но их «слушание» — ограниченный ресурс. ← [what-to-steal #3](../05-research/what-to-steal.md)
- **Рутина «ломается»**: чертёж глючит, подсовывает абсурд — дрейф жанра перед сценой ИИ. ← [what-to-steal #5](../05-research/what-to-steal.md)
- **Офис фоново анимирован**: плоттер, мерцание, коллеги — ASCII-живость как фича. ← критерий «Красиво»

**Чего игра НЕ делает сама (пока):** пуши от бота «начальник в личке» — отложены до проверки Bot API и риска раздражения ([what-to-avoid §4](../05-research/what-to-avoid.md)).
