# Что не выбрали

- **Игровой движок (Unity, Godot, Phaser)** → тяжёлый рантайм против загрузки < 2 с; ASCII-сетке не нужен сценграф и физика.
- **React / любой UI-фреймворк** → UI рисуется глифами в той же сетке; DOM-UI поверх WebGL — второй визуальный язык.
- **three.js AsciiEffect / DOM-рендер текста** → читает пиксели и строит DOM каждый кадр — медленно на телефоне ([what-to-avoid §5](../../idea/05-research/what-to-avoid.md)).
- **textmode.js как основа** → исходники закрыты, v0.x, форк невозможен; только как 1–2-дневный прототип внешнего вида.
- **WebGPU** → iOS Safari только с 26.0, Android WebView не подтверждён.
- **Аудиофайлы и TTS в демо/MVP** → процедурный звук; голос — шаг 2 ([решение по озвучке](../../idea/06-principles/README.md)).
- **Сервер на шагах 0–1** → нечего хранить, кроме сейва на устройстве.
- **Firebase / Supabase для шага 2** → зарубежное хранение персональных данных россиян конфликтует с 152-ФЗ ([технологии](технологии.md)).
- **Микросервисы, Kubernetes, очереди** → один клиент; на шаге 2 — один сервер и одна база.
- **Свой редактор уровней** → `.txt` в моноширинном редакторе хватает на 5 листов; вернуться, когда листов будет > 20 и рисовать станет больно.
- **Монетизация (Stars, реклама)** → цель — пет-проект; не раньше, чем игра докажет охват ([премортем](../../idea/07-risks/README.md)).
- **dependency-cruiser** → границы слоёв охраняет ESLint `no-restricted-imports`; второй инструмент для того же не нужен.
- **Дробный масштаб клетки** → швы и плывущие линии на Android с DPR 2,75; только целые размеры ([технологии](технологии.md)).
- **`Math.random` и время устройства в логике** → сеяный PRNG и накопленный `dt`; иначе механика не воспроизводится.
