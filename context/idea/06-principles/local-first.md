# Local-first: где живут данные

- **Демо и MVP (шаги 0–1):** сейв только локально на устройстве. Сервера нет. ← [скоуп](../04-mvp/scope.md)
- **Шаг 2:** общий прогресс между браузером и Telegram требует сервера. Локальный сейв остаётся основным, сервер — синхронизация поверх.
- **Один интерфейс сохранения** (save/load), под ним — хранилище по каналу: localStorage в браузере; в Telegram — CloudStorage (1024 ключа × 4096 символов) или тот же localStorage. ← [what-to-steal #16](../05-research/what-to-steal.md)
- **Риск:** localStorage в Android WebView может очищаться ([what-to-avoid §5](../05-research/what-to-avoid.md)) → в Telegram дублировать в CloudStorage уже в MVP (подтверждено 2026-10-13).
- **Вход в шаге 2 не только через Telegram:** при блокировке в РФ веб-игроки не должны терять прогресс → нужен запасной способ входа [решить в architecture].
- **Что уходит на сервер (шаг 2):** только прогресс; персональных данных минимум. `initData` валидируется на сервере (HMAC).
