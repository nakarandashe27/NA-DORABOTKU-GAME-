Дата проверки внешних фактов: 2026-10-13. Статусы: 🔜 решено, кода нет · 💡 требует решения.

**Жетоны на эксперименты (из 3):** ① свой ASCII-рендер на WebGL2 — оправдан, это и есть визуальная фича игры ([критерий «Красиво»](../../idea/02-vision/success-criteria.md)). ② процедурный звук на Web Audio — маленький, но свой. Третий жетон **не тратим**. Всё остальное — скучное.

## Хостинг статики — данные, на которых принято решение
Игра — статические файлы; и браузер, и Telegram WebView грузят их **с устройства игрока**, значит хостинг должен стабильно открываться из РФ.
- Cloudflare: с ноября 2024 РКН блокировал подключения с ECH; с 10.06.2025 российский трафик Cloudflare упал ~на 30%, Cloudflare подтвердила проблему; механизм — пропускаются первые ~16 КБ (тяжёлые страницы не грузятся). источник: https://zona.media/news/2025/06/27/cf-confirmed ; https://meduza.io/feature/2024/11/14/nezavisimye-media-uchatsya-obhodit-blokirovki-s-pomoschyu-kompanii-cloudflare-roskomnadzor-pochemu-by-ne-zabanit-sotni-tysyach-saytov-kotorye-ispolzuyut-ee-tehnologii (проверено 2026-10-13)
- Vercel / Netlify / Cloudflare Pages из РФ «работают через раз» — одиночные отзывы разработчиков, не измерения [непроверено]. источник: https://www.threads.com/@smirnov_sasha/post/DV-dK6HiBWP (проверено 2026-10-13)
- GitHub Pages — подтверждённых случаев блокировки не найдено [непроверено].
- РКН рекомендует отечественных хостеров. источник: https://www.kommersant.ru/doc/7808154 (проверено 2026-10-13)

## 152-ФЗ — для шага 2 💡
С 01.07.2025 действует обновлённая ч. 5 ст. 18: первичная запись персональных данных россиян на зарубежных серверах — нарушение; штраф 1–6 млн ₽, повторно 6–18 млн ₽. источник: https://companies.rbc.ru/news/SZRjtRsMIn/novyie-trebovaniya-k-obrabotke-personalnyih-dannyih-polnyij-gajd-na-2026-god/ (проверено 2026-10-13)
Telegram ID, привязанный к человеку, вероятно, персональные данные [вывод из определения, не разъяснение РКН — проверить с юристом до шага 2].
**Следствие:** шаги 0–1 персональных данных не собирают — вопроса нет. Шаг 2 — сервер и БД в РФ (Yandex Cloud / Selectel / Timeweb) [требует проверки актуальности перед шагом 2].
