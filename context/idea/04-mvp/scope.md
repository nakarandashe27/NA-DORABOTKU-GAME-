# Скоуп MVP

Путь: **Демо (шаг 0) → MVP (вертикальный срез) → Первая глава** (выбор 2026-10-13). Сроки — оценка, не обязательство.

## Шаг 0 — Демо-игрушка (~1 неделя)
Цель: проверить два главных риска — цепляет ли механика и тянет ли ASCII-рендер телефон.
- **Сначала ходячий скелет** (сборка → деплой → браузер и Telegram → сетка → тап → звук → сейв, на 3 реальных телефонах + замер из РФ), в его первый день — **тест читаемости** настоящим рендером на ширине 360 px. Пока скелет не прошёл — фичи не начинаются. ← [риск 3](../07-risks/README.md), [тестирование](../../architecture/07-нефункциональные/тестирование.md)
- Экран «проверка чертежа» в ASCII, без хаба.
- 3–5 листов с нарастанием правил, штамп + комментарий ГАПа.
- Сцена с ИИ-стажёром в конце.
- Запуск в браузере + в Telegram Web App.
- **Звук** — процедурный 8-бит синтез через Web Audio (подход procedural-film): гул плоттера, штамп, тиканье, реплики «бормотанием» (выбор 2026-10-13). Настоящего голоса в демо/MVP нет — см. [принципы](../06-principles/README.md).
- **Критерий перехода дальше:** см. [метрики](success-metrics.md).

## Шаг 1 — MVP / вертикальный срез (~2–3 недели)
- Одна комната ASCII-офиса, персонаж ходит (тап-в-точку / клавиатура).
- 2 NPC: ГАП и ИИ-стажёр.
- Мини-игра «проверка чертежа», 5 листов с нарастанием правил.
- Дуэль с ИИ в конце главы.
- 1 навык + 1 шкала репутации.
- Только русский, тексты вне кода по ключам.
- Локальный сейв.
- Telegram + браузер.

**Гейт перед шагом 2:** демо/MVP проверены на холодной аудитории (не только знакомые) — см. [вердикт премортема](../07-risks/README.md).

## Шаг 2 — Первая глава (~1,5–2 месяца)
- +2 мини-игры (раскладка альбома, плоттер).
- 3 навыка, 3 NPC, случайные события.
- Первая карьерная развилка.
- Сервер-сейв, общий прогресс, вход через Telegram (+ запасной вход, см. [local-first](../06-principles/local-first.md)).
- Озвучка ключевых реплик своим голосом через Qwen3-TTS.

## Осознанно НЕ входит в MVP
- Английский язык.
- Сервер и синхронизация между устройствами (только в шаге 2).
- Шкала выгорания и концовки (JTBD №4 — вторичный).
- Несколько комнат офиса, большое дерево веток.
- Пуши от бота «начальник в личке».
- Монетизация.
