# Правила, которые НИКОГДА не должны нарушаться

Проверяются **валидатором** (пакет `content-schema`) в CI и при сборке — сборка с нарушением не собирается; правила сейва — **при загрузке сейва**. Пересмотрено после [премортема архитектуры](../07-нефункциональные/риски-архитектуры.md).

## Базовые (контент)
- Каждый `id` уникален во всём контенте; префикс совпадает с `type` (`sheet.*`, `rule.*`…); одна форма регистра: `snake_case` после префикса.
- Каждая ссылка по `id` (включая ссылки внутри `condition`) указывает на существующую запись нужного типа.
- **id неизменяемы.** Переименование или удаление записи, на которую может ссылаться сейв (`sheet`, `defect`, `flag`, `character`), — только с записью в `renames.json` (`старый id → новый id | null`). Валидатор сравнивает список id с предыдущим релизом и падает, если id исчез без записи.
- Флаги — только из закрытого перечня записей `flag`; свободные строки запрещены.
- У каждой связи хранится одна сторона ([схема связей](схема-связей.md)); дублирующие списки (`sheet.defects[]`) не пишутся руками.
- Каждый ключ текста есть в `ru.json`; каждая подстановка в шаблоне определена.

## Файлы рисунков
- UTF-8 без BOM, переводы строк LF, без табов (проверяется в CI и `.gitattributes`).
- Все строки слоя одной длины; слои `art` и `mask` (и `walk`) одного листа/комнаты — одного размера.
- Каждый символ рисунков и текстов есть в атласе шрифта (включая `#@%!` для ругани ГАПа).
- Каждая клетка маски с номером ошибки лежит над **непустым** символом рисунка — ловит сдвиг рисунка без сдвига маски.
- Каждый символ маски соответствует ровно одному `defect.mark` этого листа, и наоборот.

## Механика (принцип «никакой угадайки»)
- Каждый `defect.rule` входит в `sheet.rules` своего листа.
- Правило активно на листе только начиная с листа, где у него есть `introLine` (подача «в лицо»); `firstSheet` вычисляется.
- **Минимальное расстояние между центрами ошибок** — не меньше порога в клетках, рассчитанного так, чтобы при **минимальном** зуме хитбокс каждой ошибки был ≥ 44 px и хитбоксы не перекрывались. Порог — функция размера клетки из [карты системы](../01-обзор/карта-системы.md#системы-координат); проверяет валидатор, не рендер.
- Конфликт хитбоксов при тапе (если всё же случился) решается правилом «ближайший центр».
- `voice.lieChance` < 0.5. Ложь голоса определяется сеяным PRNG — повтор того же листа с той же попыткой даёт тот же результат.
- `sheet.listens` ≥ 0; `timeLimitSec` > 0.
- Длина реплики в клетках ≤ ширины текстовой области при минимальной ширине экрана (360 px).

## Сейв
- Формат один — [сущности](сущности.md); у сейва есть `v`, и каждая версия схемы имеет миграцию из предыдущей + зафиксированный сейв-образец в тестах.
- Перед миграцией — копия в отдельный ключ `save.backup.v{N}`.
- Копии **сливаются** по правилам из [сущностей](сущности.md), не перезаписываются; время устройства не арбитр.
- `results[sheetId]` пишется один раз за попытку; повтор листа — явное действие «переиграть» (`attempt + 1`).
- `found` содержит только `defect.id` этого листа, без повторов.
- Событие с флагом в `flags` повторно не запускается.
- id из сейва при загрузке проходят через `renames.json`; оставшиеся неизвестные id игнорируются с записью в лог (dev) — сейв не падает.
- Сейв < 4096 символов (лимит ключа Telegram CloudStorage).

## Контент и тон
- В тексты не попадают слова из запретного списка [характера](../02-ядро/характер.md) — простая проверка по списку в валидаторе.
