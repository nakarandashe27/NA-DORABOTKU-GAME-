# One-person company: соло-разработка

Проект — пет-проект одного человека (+ Claude как исполнитель кода). Следствия:
- **Без ассетов** — нет художника и звукорежиссёра → всё процедурно (принцип 5).
- **Без бэкенда до шага 2** → нечего администрировать и оплачивать на старте.
- **Минимум зависимостей**: свой тонкий WebGL2-рендер глифов; textmode.js — только для 1–2-дневного прототипа (закрытые исходники). ← [what-to-avoid §5](../05-research/what-to-avoid.md)
- **Тексты вне кода с первого дня** — дешёвая страховка под будущий EN. ← [segments](../03-audience/segments.md)
- **Скоуп — фильтр каждой фичи**: нужна ли для текущего шага? Нет → в бэклог.
- **Валидация дёшево**: плейтест на 10 знакомых архитекторах до любых вложений в хаб. ← [метрики](../04-mvp/success-metrics.md)
