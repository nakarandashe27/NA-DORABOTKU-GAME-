# KPI

Источники: [метрики MVP](../../idea/04-mvp/success-metrics.md), [критерии успеха](../../idea/02-vision/success-criteria.md).

| Метрика | Цель | Когда меряем |
|---|---|---|
| Плейтест: прошли все листы | ≥ 5 из 10 | демо |
| Плейтест: переслали | ≥ 3 из 10 | демо |
| FPS на среднем Android | ≥ 50 | скелет, демо, MVP |
| Загрузка в Telegram | < 2 с | скелет, демо, MVP |
| Запуски за 2 недели после публикации | ~1000 | MVP |
| Доля дошедших до сцены ИИ (холодная аудитория) | ≥ 50% | MVP |
| D1 retention | гипотеза ≥ 25% | MVP |
| Девлог: роликов в неделю | 2–3 | еженедельно |

Живых (`[LIVE]`) метрик пока нет — аналитика появится на этапе 22 [roadmap](../../architecture/08-дорожная-карта/roadmap.md).
