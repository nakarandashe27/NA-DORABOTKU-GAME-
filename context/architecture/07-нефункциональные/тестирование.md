# Тестирование

Ответ на [архитектурный риск 3](риски-архитектуры.md): код пишет AI, поэтому каждое правило архитектуры исполняется кодом, а не текстом.

## Правило для AI-сессий
- Задача без теста или без команды проверки не принимается.
- Удалённое удаляется: никаких закомментированных веток, прототипов «на потом», второго пути рендера вне интерфейса `Renderer`. `knip` в CI ловит неиспользуемый код.
- Новый метод Telegram SDK — только после сверки с https://core.telegram.org/bots/webapps; память модели о SDK не источник.

## Уровни тестов
| Уровень | Что | Инструмент | Где запускается |
|---|---|---|---|
| 1. Чистое ядро | механика листа (тап → ошибка, штамп, итоги), PRNG и ложь голосов, `condition`, автомат сцен, `screenToCell`, перенос слов, слияние и миграции сейва (на зафиксированных сейвах каждой версии), валидатор контента | Vitest | CI, каждый push |
| 2. Рендер без пикселей | ядро → буфер ячеек; **оба бэкенда** (WebGL2, Canvas2D) рисуют один буфер — сравнение снимков | Vitest + Playwright | CI |
| 3. Смоук | игра открывается, лист проходится записанной последовательностью тапов («golden run» — одинаковый итог и сейв), сейв переживает перезагрузку; вьюпорт 360×640 | Playwright: Chromium и WebKit; флаг `?renderer=canvas` | CI |
| 4. Реальные устройства | матрица ниже, вручную | телефон + `chrome://inspect` / Safari Web Inspector | ворота шагов |

## CI (GitHub Actions, каждый push)
`tsc --noEmit` → ESLint (границы слоёв, запреты в `core`) → Vitest → валидатор контента → сборка → бюджет размера (сборка + атлас; порог — из цели загрузки < 2 с) → `knip` → Playwright-смоук. Красный CI = деплоя нет.

## Ворота
1. **Ходячий скелет** (первая неделя, до любых фич): сборка → деплой на свой домен → платформа (браузер и Telegram) → сетка рисует лист-заглушку → тап попадает в клетку → звук-пик → сейв переживает перезагрузку и сворачивание → **на всех трёх телефонах** + замер загрузки из РФ. Пока не пройдено — фичи не начинаются.
2. **Тест читаемости** (день 1 скелета): настоящий рендер, лист, минимальный размер клетки, реальный телефон. Не читается → менять размер клетки/подачу до контента ([скоуп](../../idea/04-mvp/scope.md)).
3. **Демо → MVP**: все уровни зелёные + метрики плейтеста ([метрики](../../idea/04-mvp/success-metrics.md)).
